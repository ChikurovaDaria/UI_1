# Личная библиотека Дарьи Чикуровой

Адаптивное портфолио на HTML, CSS и обычном JavaScript. Пять книг открывают разделы об авторе, дизайне, 3D, играх и контактах. На широком экране показан разворот, на узком — одна страница.

## Запуск

Откройте `index.html` в современном браузере. Для разработки можно использовать Live Server в VS Code. Сборка и npm не нужны. Шрифты загружаются из Google Fonts; при отсутствии сети используются системные шрифты.

## Добавление работ

Все четыре карточки сейчас являются местами для будущих работ, а не готовыми проектами. Откройте массив `projects` в `main.js`:

- `id`: уникальное обозначение проекта;
- `title`, `description`: название и краткое описание;
- `category`: `design` (Дизайн) или `dimensional` (3D / игры);
- `section`: книга `design`, `volume` или `games`;
- `image`: относительный путь, например `./images/poster.jpg`. Создайте папку `images` рядом с HTML и положите туда свою картинку. При пустом пути или ошибке загрузки остаётся бумажная заглушка;
- `details`: задача (`task`), идея (`idea`), моя роль (`role`), процесс (`process`), результат (`result`).

Скопируйте объект для добавления новой работы. Текст выводится через `textContent`, без `innerHTML`. Проекты автоматически появляются в общем каталоге и в соответствующей книге. Не используйте HTML-разметку внутри текстовых полей.

## Контакты и биография

В объекте `contacts` в `main.js` заполните `email`. Социальные ссылки добавьте в `socials`, например `{ label: 'Моё портфолио', url: 'https://ваш-адрес' }`, заменив адрес настоящим. Пустые и некорректные контакты не превращаются в ссылки. Форма отправки сообщений отсутствует.

Образование редактируется в шаблоне `pages-about` в `index.html`. Остальные тексты книг — в шаблонах `pages-*`. Не забудьте обновить краткий текст внутри `noscript`, если измените биографию.

## Функции JavaScript

Фильтры «Все», «Дизайн», «3D / игры»; тема с сохранением в localStorage и обработкой недоступного хранилища; мобильное меню с aria-expanded; книги с перелистыванием; подробности проектов в нативном dialog с закрытием по Escape и возвратом фокуса. Учитывается prefers-reduced-motion.

## Что проверить перед сдачей

1. Нажмите все фильтры: ожидается 4 / 2 / 2 карточки при исходных данных. При удалении всех проектов категории появляется сообщение об отсутствии работ.
2. Переключите тему и обновите страницу: тема должна сохраниться. Проверьте оба оформления.
3. На ширине 360 px откройте меню, выберите пункт; повторите закрытие по Escape.
4. Откройте каждую книгу, листайте стрелками и кнопками. На компьютере — по две страницы, на телефоне — по одной. Вернитесь на полку.
5. Откройте «Подробнее» из каталога и книги. Закройте кнопкой и Escape: фокус должен вернуться к исходной кнопке.
6. Проверьте ширины 360, 768 и 1440 px, отсутствие горизонтальной прокрутки, навигацию Tab/Enter и реальные контактные ссылки после заполнения.

## GitHub Pages

Создайте репозиторий и загрузите `index.html`, `style.css`, `main.js`, `README.md` и свои изображения в его корень. В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`. Сохраните и дождитесь успешной публикации. Откройте URL из Pages и повторите проверки. Для сдачи нужны ссылка на сайт и ссылка на репозиторий.
